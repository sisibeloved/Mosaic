# Mosaic v0.5.5 — 职责准入：能力核对、权限交集与 readiness report（0.5 长期 Agent 与职责领域·第六件·收官）

0.5.2 定义了职责，0.5.3 让它存在，0.5.4 交付任职；本版交付**准入**：谁有资格承担某个职责——用户授权与模板要求的交集判定。至此 0.5 长期 Agent 与职责领域（0.5.0–0.5.5）全部交付。

## 新增

- **AgentGrant 授权档案**（RFC-0018 §5.2 / ADR-0022，migration v12）：用户授权侧——技能（ref@vN）、工具、上下文域、运行能力、工作区权限；一 Agent 一档全量替换。**无档案 = 空授权**（安全缺省）：模板声明的一切必需项缺失即 blocked；模板未声明要求的职责不受影响——无隐式门槛。
- **交集单源 EvaluateReadiness**：skills 模板列出即必需（授权版本 ≥ 引用版，向后兼容）；tools/context/runtime 必需项缺失 → **blocked**；选配缺失 → **降级有报告**（AT-07）；工作区权限格栅 none < read < read_write，**有效权限 = min(授权, 模板要求)**——交集语义，授权直通不成立。
- **真实准入门**：0.5.4 预埋的 ReadinessChecker 端口实装（GrantReadinessChecker）——生产从此有真实 blocked；blocked 事件记缺失与降级两清单；**不自动换人、不自动扩权**，修复路径唯一：改授权档案 → 重试。
- **激活两时点复核**：ready 只代表建任职时点就绪；激活按钉住模板版本重算交集，必需项缺失 409 `readiness_not_met` 可见拒绝（RFC §11"必需能力缺失则拒绝激活"；与 Agent active 两时点校验同口径）。
- **API 四端点**：授权档案 GET/PUT（未设置 404 = 可编辑空表单；缺必填字段/null 400，半体请求不清空既有授权）、实例**准入试算**（只读无副作用，未就绪也是 200——报告不是错误；版本三态与建任职同规则）、blocked **重试准备**（单事务）；写面经生产写门。
- **设置页**：「Agent 授权档案」管理块（加载期间表单锁定、归属核对——切档残留内容不覆盖他人授权）；实例任职行**准入试算**（就绪/缺失/降级/有效权限即时报告）与 blocked 展示（缺失清单 + 重试按钮）。

## 修复（独立审校 2 项 P1、4 项 P2）

- **切换 Agent 后不再把授权保存给错误对象**：表单记录所属 Agent，档案加载期间禁编辑禁保存，保存前核对归属。
- **撤销必需授权后旧任职不再能激活**：激活时点按钉住版本复核，缺失 409 可见拒绝。
- **迟到的试算结果不再显示在新选择下**（请求序号守卫）；**非法版本号就地拒绝**（空 = 最新，非空必须正整数——试算与建任职同规则）。
- **ADR-0022 强隔离验收阶段归属更正**：强隔离准入随 0.6 Runtime/Mission 域交付（P1 出口），P4 仅环境变更后复验。
- **缺必填字段的授权 PUT 不再清空既有授权**：缺键或 null 一律 400，清空须显式空数组。

## 升级说明

- v0.5.4 数据库首次启动自动建 `slot_agent_grants` 表（migration v12），无需手工步骤；旧版本二进制可直接升级本库，回退不受影响（新增表对旧版不可见）。
- **行为变化**：生产装配了真实准入门——声明了必需要求的职责模板，未补授权的任职将 blocked（AT-07 要的行为）；此前的无要求模板链路完全不变。效果可在设置页「职责 → Agent 授权档案 / 实例 → 任职（准入试算）」与 `GET /v1/slots/instances/{id}/readiness` 核对。
- 设计基线：[RFC-0018](docs/design/rfc/2026-10-28-rfc-0018-personal-agent-swarm.md)（Approved）与 [ADR-0022](docs/design/adr/ADR-0022-readiness-admission.md)；**0.5 领域线至此收官**，下一领域为 0.6 Mission 与本地执行（排空门实装、在途工作处置、强隔离 Runtime 准入）。
