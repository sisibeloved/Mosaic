# Mosaic v0.6.4 — RuntimeLease：工作区占用、互斥与围栏代次（0.6 Mission 与本地执行领域·第五件）

0.6.3 让运行时可发现、可准备；本版交付"**谁在用、用到何时、旧实例提交如何拒绝**"的租约底座——0.6.5 调度的"领取 → 执行 → 续租心跳 → 释放/到期 → 围栏校验"全链原语就此齐备。

## 新增

- **RuntimeLease**（RFC-0018 §5.2/§10.3.1 / ADR-0027，migration v17+v18）：`runtime_leases` 一表 + 双部分唯一索引承载互斥——**同一可写工作区至多一个活跃租约（跨运行时）** + 单运行时并发 1（首版单 Agent 串行）。
- **领取**：前置 runtime ready 且已绑环境、占用主体（mission）存在且非 canceled；代次 = 当代 MAX+1 并签发 `fnc_` 围栏令牌；TTL 缺省 3600s（界限 60–86400，字段存在即校验）；`resource_limits` 为声明（强制随 0.6.5）。
- **围栏代次**：代次单源于租约行（运行时当代 = MAX(generation)）；释放/到期经状态终态化使旧令牌失效，新领取代次自此超过旧租约。**check-fence 四关**（令牌 → active → 未过期 → 当代）恒 200 携 reason——0.6.5 结果提交经此拒绝旧实例提交（围栏只保护 Mosaic 接收的状态与受控工具调用，不撤销外部已发生动作）。
- **生命周期**：active → 释放/到期 → 终态；**renew 即心跳**（从现在起延长）；**到期惰性判定**（触碰即转，读面不出现过期仍标 active 的行）；busy 派生化（租约存在即忙，不占运行时状态名）。
- **API 六端点**（领取/列表/详情/续租/释放/围栏校验）+ 运行环境页租约诊断区（RFC §13：细节归诊断视图，领取是 0.6.5 调度行为不做人工入口）。

## 修复（独立审校 1 项 P1、4 项 P2、1 项 P3）

- **旧续租不再复活已过期租约及原令牌**：续租/释放改原子条件更新（只改目标字段、active 条件、获锁后重取时间）——并发到期先落则 409，状态/到期/令牌三不变。
- **目录别名不再绕过工作区独占**：`workspace_key` 规范身份（EvalSymlinks）+ 部分唯一索引——符号链接别名建面 409、直改拦截、领取面身份排他兜底（migration v18，含开发期旧库升级）。
- **到期扫描不再覆盖成功续租**：单语句原子判定+转移（datetime() 比较）。
- **显式 `ttl_seconds: 0` 拒收**（400）——字段存在即校验界限，省略才用缺省。
- **已终止租约的释放按钮**：遇 lease_inactive 刷新诊断列表并保留说明。
- **generation 文档对齐实现**（领取分配 MAX+1；终态化使旧令牌失效）。

## 升级说明

- v0.6.3 数据库首次启动自动建 `runtime_leases` 表（migration v17）并为 environments 增 `workspace_key` 列（migration v18），无需手工步骤；旧版本二进制可直接升级本库。
- 租约目前由 API/诊断面管理；调度领取与 Run 关联（`run_id`）随 0.6.5 单 Agent 执行落地——届时本版原语（领取/续租/释放/围栏）被完整消费。
- 设计基线：[RFC-0018](docs/design/rfc/2026-10-28-rfc-0018-personal-agent-swarm.md)（Approved §5.2/§10.3.1）与 [ADR-0027](docs/design/adr/ADR-0027-runtime-lease.md)（v0.2）。
