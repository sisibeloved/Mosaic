# Mosaic v0.7.2 — 记忆召回：FTS5 与授权过滤先行（0.7 记忆与可移植恢复领域·第三件）

0.7.1 交付策展后，记忆仍只能按域翻列表——找记忆没有召回入口。本件按 RFC-0018 §7.3/§7.4 交付召回：**SQLite + FTS5 trigram 全文索引 + "授权及有效期过滤先于排序与计数"铁律**。两轮独立审校（4 + 2 = 6 项）全部关闭后定版。

## 新增

- **召回入口**：`GET /v1/memory/items` += 可选 `q`——≥3 字走 FTS5 MATCH（trigram tokenizer，room_fts/doc_fts 同裁定：unicode61 中文整串单 token 不可用；phrase 引号防语法注入）；<3 字回退 LIKE 子串（`ESCAPE` 字面转义——`%`/`_`/`\` 不作通配）。
- **FTS5 索引**（migration v33）：`memory_fts(title, content)`；AI/AU 触发器**同事务同步**（策展修订/替代路径零改动——修订后旧词不中新词中）；存量回填幂等。
- **过滤先行**（RFC §7.3 铁律，SQL 层固化）：namespace（授权）+ scope/kind/status + 时效过滤与匹配**同一查询**——他域命中不出现在结果也**不计入 `total_hits`**（存在性不泄漏）；0.7.1 的默认排除过期在召回同样生效（`include_expired=true` 显式可见）。
- **语料内评分**：bm25 精排的统计（dl/avgdl/tf）**限定于过滤后语料**——过滤外条目的增删不改变本域排名与 total（FTS5 内建 bm25 的全索引统计会污染排名，故 MATCH+过滤驱动取候选后 Go 侧精排）；相关度降序、rowid 兜底；召回模式无游标（limit 截断）。
- **`total_hits`**：过滤+匹配后总数（不含分页截断；每页恒定——与 `before` 游标解耦）；非召回模式同给。
- **SPA**：记忆页搜索框（召回词与浏览条件同源刷新）+ 结果总数显示。

## 修复（两轮独立审校 6 项）

- **一审（1 P1 + 3 P2）**：召回改 MATCH 索引驱动 JOIN（原逐候选 bm25 子查询对过滤后每行全扫 FTS 表——受控 1000/9000 命中约 1.56/14 秒；修复后 9000 命中约 0.1 秒）；LIKE 字面 `%`/`_`/`\` 转义 + ESCAPE（原通配误命中全部）；`total_hits` 与分页解耦（七条 limit=2 每页恒 7）；bm25 评分与 MATCH 共享游标（原独立子查询脱离 MATCH 上下文恒零、退化为纯创建序——旧强命中被新弱命中挤出）。
- **二审（2 P2）**：MemStore 游标定位提前至状态/时效过滤前（游标条被撤回/过期不再漏续页）；召回排名限定语料内（原 FTS5 全索引 avgdl 统计——任一过滤面外增一条长文即翻转本域排名）；性能代表性回归提升至受控 2000 命中 <1s（实测 0.15s）。

- v0.7.1 数据库首次启动自动执行 migration v33（memory_fts 虚拟表 + 触发器 + 存量回填，幂等）。
