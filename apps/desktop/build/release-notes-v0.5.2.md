# Mosaic v0.5.2 — SlotSpec 版本化职责模板（0.5 长期 Agent 与职责领域·第三件）

0.5.0 给了 Agent 独立身份，0.5.1 给了它生命周期；本版交付职责的定义本身——**版本化、不可变的职责模板**（RFC-0018 §5.1 候选语义的正式定形，ADR-0019），为 0.5.3 职责实例、0.5.4 任职管理与 0.5.5 准入打地基。

## 新增

- **不可变版本行**：`slot_specs`（migration v9）以 `(slot_spec_id, version)` 为主键——修订即追加新版本（并发追加串行化为连续版本号，无空洞无重复），无更新/删除路径，历史版本永不清除；版本行本身即完整历史，为未来 Binding 固定版本引用提供审计前提。
- **内容 Schema 定形**：名称 / 职责陈述 / 交付规范必填；可选段——技能引用（仅引用，不含可执行体）、工具与上下文的**必选/可选分层**（必选缺失将 blocked、可选缺失按声明降级——0.5.5 准入的语义预埋，两者不得相交）、委派策略（缺省 = 不允许委派）、运行时能力要求（能力名而非安装路径）、交接必备件。校验单源：必填/上限/模式/枚举全拒不合规件。
- **谱系标识**：`slot.` 前缀小写 slug（如 `slot.research-lead`），用户选定、跨版本稳定——要进配置与导出引用，人类可读是功能。
- **五端点 API**：建谱系（重复 409）、追加版本、谱系摘要、最新全量、全版本升序；写端点经生产写门（回环 Origin + X-Owner-Token）。
- **设置页「职责」区**：谱系列表（最新版本徽标/版本数/修订时间）、新建模板表单（核心字段 + 必选/可选工具）、按最新版本预填的修订流、版本历史明细。

## 修复（独立审校六项）

- **修订不再丢配置（P1）**：修订以完整最新模板为基线，表单未覆盖段（技能/上下文/委派/运行时/交接）逐字带入——只改名称，其余配置原样进入新版本。
- **交付规范仅按行拆分**：逗号是条目内容的一部分，不再被拆散或超限。
- **空运行时段拒绝**：`workspace_access` 缺失或空串在创建与追加两条路径均返回 400（契约枚举三值封闭）。
- **追加后版本历史必见新版本**：读取直接依赖刷新标记并丢弃迟到响应。
- **读取失败不再伪装"暂无版本"**：单列错误提示与重试入口，只缓存成功结果。
- **迟到的修订加载不再覆盖草稿**：等待期间新建/取消/切换模板自动作废在途响应。

## 升级说明

- v0.5.1 数据库首次启动自动建 `slot_specs` 表（migration v9），无需手工步骤；效果可在设置页「职责」区与 `GET /v1/slots/specs` 核对。
- 旧版本二进制可直接升级本库；回退不受影响（新增表对旧版不可见）。
- 设计基线：[RFC-0018](docs/design/rfc/2026-10-28-rfc-0018-personal-agent-swarm.md)（Approved）与 [ADR-0019](docs/design/adr/ADR-0019-slotspec-versioned-template.md)；后续 0.5.3 起交付职责实例与任职体系。
