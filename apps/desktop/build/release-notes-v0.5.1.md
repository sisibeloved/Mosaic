# Mosaic v0.5.1 — Agent 生命周期状态机与事件流（0.5 长期 Agent 与职责领域·第二件）

0.5.0 给了 Agent 独立身份；本版给这份身份一条**可审计的生命周期**：暂停、退役与全程事件史，为后续 Slot 任职、Mission 委派（0.5.2+/0.6）提供状态依据与承诺门挂靠点。

## 新增

- **生命周期状态机（RFC-0018 §3.2 / ADR-0018）**：`active ↔ suspended；active|suspended → retiring → retired`（retired 唯一终态）。暂停/恢复/退役均为显式操作；非法转移一律可见拒绝（409），不静默吞掉状态漂移。`active` 不代表正在运行——身份状态，不是进程状态。
- **事件流（migration v8）**：`agent_events` append-only 流记录 `created` 与 `status_changed`（含原因）事件；v0.5.0 存量库首次启动自动按创建序回填，重开不重复。`agents` 表自此降为投影——事件流完整覆盖历史，可重建。
- **原子退役与承诺门**：退役经承诺门（"处置所有承诺后才能 retired"）——当前版本无 Mission/Binding 域、承诺集恒空，一次操作即完成；承诺门接口已就位，后续域接入后未处置承诺将以清单形式呈现并停留"退役中"。
- **同步与生命周期解耦**：已暂停/已退役身份的可执行项重装或重扫**不复活状态**；新发现的身份仍以活跃态出生。退役不等于卸载——身份级状态，可执行项照常可用。
- **身份写面 API**：`POST /v1/identity/agents`（手动建身份）、`POST /v1/identity/agents/{id}/lifecycle`（暂停/恢复/退役）、`GET /v1/identity/agents/{id}/events`（事件审计）；写端点经生产写门（回环 Origin + X-Owner-Token）。
- **设置页「Agent 身份与生命周期」区**：身份列表（展示名/家族/状态徽标/挂靠可执行数）、暂停/恢复/退役按钮（退役需确认）、生命周期事件明细（展开即查）。

## 修复（独立审校五项）

- **并发操作不再返回 500**：身份写事务全部改为先取写锁再读（BEGIN IMMEDIATE）——并发冲突稳定按 409 语义返回败者（100 次重复并发测试与 HTTP 层 8 路并发实测零异常）。
- **退役中断不再滞留"退役中"**：空承诺门的退役为单事务一次提交（两段事件 + 终态），中途失败整体回滚。
- **操作后事件明细即时刷新**：暂停/恢复/退役成功后，已展开的生命周期事件明细立即重读，连续操作每次拿到最新历史。
- **手动登记后新身份立即可管理**：登记/启停可执行项后身份列表同步刷新。
- **旧响应不再覆盖新状态**：连续操作时较慢的旧响应被请求序号拦截，已显示的终态不会被回写成旧态。

## 升级说明

- v0.5.0 数据库首次启动自动完成 v8 迁移与事件回填，无需手工步骤；效果可在设置页身份区与 `GET /v1/identity/agents/{id}/events` 核对。
- 旧版本二进制可直接升级本库；回退不受影响（新增表对旧版不可见）。
- 设计基线：[RFC-0018](docs/design/rfc/2026-10-28-rfc-0018-personal-agent-swarm.md)（Approved）与 [ADR-0018](docs/design/adr/ADR-0018-agent-lifecycle.md)；后续 0.5.2 起交付 SlotSpec / SlotInstance 职责体系。
