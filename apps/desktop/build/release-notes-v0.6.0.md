# Mosaic v0.6.0 — MissionContract 独立事实源：版本化契约与契约状态（0.6 Mission 与本地执行领域·第一件）

0.5 交付了"谁"（身份/职责/任职/准入）；0.6 交付"办成一件事"的闭环，第一件是**契约**：交办从聊天记录变为可验收的独立事实。

## 新增

- **独立事实源**（RFC-0018 §3.1 / ADR-0023，migration v13）：`mi_` 生成式 ID；missions 投影 + **不可变契约版本行**（修订即追加，历史永不清除）+ mission_events 事件流（created / contract_revised / status_changed，写路径单事务）；归 Workspace 不挂 Room——退出/关闭房间不级联影响 Mission（房间来源引用随 0.6.1）。
- **契约内容**（§6.1 的 0.6.0 子集）：目标 / 范围 / 约束 / 验收标准 / 交付物 / 来源引用 / 返回位置 / 预算 / 委派策略 / 验收人 + 负责人；`decision_ref`、`context_manifest_ref` 随 0.6.1/0.6.2 增列（对象未存在不落空壳字段）。**预算安全缺省**：单 Agent、32 Run 上限、一天墙钟、不重试、不委派——契约声明事实，运行时强制随 0.6.5 Scheduler。
- **契约状态** draft / ready / canceled：完备性判定单源——验收/来源/交付物缺失或未指派负责人 → draft（保存明确请求，不捏造共识）；齐备且已指派 → ready（执行随 0.6.5 起）；canceled 唯一终态。
- **版本与 CAS**（AT-13）：修订 = 全量替换 + 版本追加，`expected_version` 必填——**并发修订恰一胜者**，败者 409 `version_conflict` 拿回当前版本可见重试，不静默合并；完备性在修订上重判（draft ↔ ready 双向事件留痕）；终态拒修订/重复取消 409。
- **API 七端点**：创建 / 列表 / 详情 / 修订（CAS）/ 取消（原因入事件）/ 版本列表 / 事件流；必填字段缺失或 null、显式非法预算一律 400 且零改动（显式空数组才是清空语义）；写面经生产写门。
- **/missions 任务中心**（新页面 + 导航）：创建表单（含预算高级项与负责人下拉）、契约列表（状态徽标 + 版本）、详情（当前契约 + 版本历史 + 事件流）、修订（未编辑字段与预算从完整快照保留——不被全量替换语义清空；CAS 冲突 409 可见）、取消（原因输入）；切换任务即隔离详情与草稿，加载完成且目标一致才允许写入。

## 修复（独立审校 2 项 P1、1 项 P2）

- **切换任务不再误写他人**：详情/草稿按任务隔离 + 写入归属守卫（加载完成且 mission_id 一致才可修订/取消）。
- **普通修订不再清空未编辑字段、重置预算**：修订请求从当前契约完整快照构造（实测预算 2 Run/600s 曾被重置为默认 32/86400s）。
- **缺字段或非法预算不再被接受**：必填五键存在性 + budget 键在场严格界限校验（全零 400），无效请求零改动。

## 升级说明

- v0.5.5 数据库首次启动自动建 missions / mission_contract_versions / mission_events 三表（migration v13），无需手工步骤；旧版本二进制可直接升级本库，回退不受影响（新增表对旧版不可见）。
- 本版只交付契约事实：执行 / 调度 / Run / 验收 / 回房随 0.6.3–0.6.12；预算暂为声明事实而非运行限制（0.6.5 起强制）。效果可在「任务」页与 `GET /v1/missions` 核对。
- 设计基线：[RFC-0018](docs/design/rfc/2026-10-28-rfc-0018-personal-agent-swarm.md)（Approved）与 [ADR-0023](docs/design/adr/ADR-0023-mission-contract.md)（含 Dispatch 排布裁定：网关首切片随 0.6.1 房间交办落地）。
