# Mosaic v0.5.3 — SlotInstance 职责实例与独立知识命名空间（0.5 长期 Agent 与职责领域·第四件）

0.5.2 定义了职责（SlotSpec 版本化模板）；本版让职责**存在**于具体作用域中——某处实际承担着的一份职责（SlotInstance），并为它登记独立的知识命名空间。

## 新增

- **职责实例**（RFC-0018 §3.1 / ADR-0020）：`si_` 前缀生成式实例 ID；引用模板**谱系**而不固定版本（固定版本是任职 Binding 的职责，0.5.4；实例只记 `created_from_version` 审计事实）；同一模板可实例化多份；换人后实例保留——实例属于作用域，不属于任何任职者。
- **独立知识命名空间**：每个实例生成 `slotns_` 前缀的全局唯一、终身稳定、永不重派的命名空间——职责知识挂实例命名空间，**绝不挂任职者的私有库**；该命名空间即未来分域记忆（0.7）的登记地址。
- **存档与现势分离**：实例标题缺省取实例化时模板最新名**存档**（模板后续改名不回写）；视图另携模板**现势**连接（当前名称/最新版本，随模板演进）——并发下读取顺序保证现势恒不旧于创建版本。
- **API 三端点**：实例化（省略标题取模板名、显式空标题 400、谱系未知 404）、实例列表（创建序 + 现势连接）、实例详情；写端点经生产写门。
- **设置页「职责实例」区**：模板下拉 + 可选标题的实例化表单；实例列表（模板现势徽标、自 vN 实例化、知识命名空间徽标）。

## 修复（独立审校五项）

- **并发下列表不再出现矛盾版本**：组装改为先读实例后读模板并加防御钳制（现势恒 ≥ 创建版本；并发追加/实例化/读取交替施压验证）。
- **模板读取失败不再伪装成功详情**：现势读取错误如实返回 500，不再吞错给出空名与版本 0。
- **显式空标题拒绝**：省略 → 取模板名；显式空串/纯空白 → 400（三态区分）。
- **实例列表读取失败可恢复**：单列错误提示并保留最近成功列表，显式重试。
- **修订模板后实例徽标即时跟进**：模板提交成功后实例现势同步刷新（存档标题与来源版本不变）。

## 升级说明

- v0.5.2 数据库首次启动自动建 `slot_instances` 表（migration v10），无需手工步骤；效果可在设置页「职责」区与 `GET /v1/slots/instances` 核对。
- 旧版本二进制可直接升级本库；回退不受影响（新增表对旧版不可见）。
- 设计基线：[RFC-0018](docs/design/rfc/2026-10-28-rfc-0018-personal-agent-swarm.md)（Approved）与 [ADR-0020](docs/design/adr/ADR-0020-slotinstance-knowledge-namespace.md)；后续 0.5.4 起交付 Binding 任职管理与职责准入。
