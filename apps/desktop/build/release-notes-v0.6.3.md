# Mosaic v0.6.3 — 本地 Environment / Runtime（0.6 Mission 与本地执行领域·第四件）

0.6.2 固定了"执行什么"；本版交付"**在哪执行、用什么执行**"——工作区环境与运行时从此是可发现、可探测、可准备、可查健康历史的持久事实。0.6.5 调度的"当前可执行"实时复核（RFC §9.2）有对象可查。

## 新增

- **Environment（命名工作区目录）**（RFC-0018 §3/§6 / ADR-0026，migration v16）：目录唯一（规范化判重）、默认环境恰一（部分唯一索引）并由启动自动确保（`<数据目录>/workspace` 落盘）；建环境即验证/创建目录。
- **Runtime 记录**：`(adapter, host, distro, path)` 唯一发现幂等键——从 harness 注册表单向搬运不回写；既有行同步只刷新镜像事实（版本/登录/渠道），状态、绑定与发现时间是本域事实不被覆盖。
- **状态机 0.6.3 子集**：`discovered →（准备：绑环境 + 确保目录 + 探测）→ ready`；探测失败 → `unhealthy`（原因可见：`executable_gone` / `version_probe_failed`）；恢复且已绑环境 → `ready`。登录态是记录事实而非 ready 门（调度分层随 0.6.5）；busy/draining/stopped 随 0.6.4/0.6.5。
- **发现触发面**：启动扫描后自动同步；手动「发现同步」**先做有超时的宿主扫描再镜像**——启动后新装的 CLI 免重启可发现；手动登记可执行程序后即同步。
- **探测面**：harness 新增只读 `Reprobe`（按登记 ID 重跑完整探测不回写）；探测成功 = 文件存在且版本探测非空（版本命令非零退出的错误文本不作数）。
- **runtime_events 流**：发现/健康检查/状态变更历史可查；并发首次同步零孤儿事件（事件在事务内只为真正插入的行生成）。
- **API 九端点** + 运行环境页（状态徽标、健康检查、准备（环境选择与换绑）、健康与状态历史、环境管理、发现同步）。

## 修复（独立审校 1 项 P1、7 项 P2、1 项 P3）

- **启动后新装的 CLI 可被发现**：手动同步先扫描再镜像，不再只读启动缓存。
- **版本命令失败不再误标 ready**：两个探测分支都要求退出码为零。
- **迟到的健康检查不再覆盖准备结果**：健康检查与准备按运行时串行（读-探测-写全程持锁）。
- **同一目录不能登记两个环境**：`/dir` 与 `/dir/.` 规范化后判重。
- **并发首次同步不再产生孤儿事件**。
- **拼错准备字段被拒收**（400），不再静默走默认环境。
- **页面**：事件区区分加载中/失败可重试/空列表；操作后已展开历史自动刷新；创建等待期间改填的输入不被旧回调清空。

## 升级说明

- v0.6.2 数据库首次启动自动建 `environments` / `runtimes` / `runtime_events` 三表（migration v16），无需手工步骤；旧版本二进制可直接升级本库。
- 默认环境在首次启动时自动创建（数据目录下 `workspace/`）；已有 CLI 经启动扫描自动入册为 `discovered`——在「运行环境」页选择环境后「准备」即就绪。执行与租约随 0.6.4/0.6.5。
- 设计基线：[RFC-0018](docs/design/rfc/2026-10-28-rfc-0018-personal-agent-swarm.md)（Approved §3/§6/§9.2）与 [ADR-0026](docs/design/adr/ADR-0026-local-environment-runtime.md)（v0.2）。
