# Mosaic v0.5.0 — 独立 Agent 身份注册表（0.5 长期 Agent 与职责领域·首件）

本版开启 RFC-0018（长期 Agent、Slot 与圆桌到 Swarm 的协作闭环，已获批）的 0.5 领域线：**Agent 第一次成为跨房间、跨部署位置存在的稳定主体**，不再寄生在可执行程序的登记信息上。

## 新增

- **独立身份权威（ADR-0017）**：Agent 身份从 `harness-registry.json` 迁入 SQLite（migration v7：`agents` + `agent_aliases`）。每个唯一 BotID 生成 `ag_` 前缀的持久 AgentID；启动自动迁移磁盘存量，幂等可重入。
- **旧 ID 别名解析**：bot_id / profile_id / participant_id 三类旧 ID 收敛为只增别名——历史房间事件里的参与者 ID 从此有统一解析点；派生公式单源化并有逐字节等价测试钉住（存量引用不漂移）。
- **单向同步**：注册表 → 身份表只增不改（可执行项消失不删身份；重绑路径身份延续；别名碰撞不合并、记冲突日志待人工处置）；可执行发现表只持有对 AgentID 的引用（`agent_id` 增量字段），旧 API 输出保持旧 ID。
- **身份 API**：`GET /v1/identity/agents`（列表：别名集 + 可执行项引用）、`GET /v1/identity/agents/{agent_id}`（详情 / 404），只读无写门。
- **设置页身份徽标**：可执行项行显示 `ag_*` 身份（悬停见完整 ID 与别名说明）；手动登记后即时出现。

## 修复（独立审校四项 + 附带）

- **并发/中断不再产生重复身份**：建行与 bot_id 别名认领为同一事务的原子 get-or-create（并发竞争回读胜者、中断不留半行；16 路真实 SQLite 并发与 8 路服务层并发测试钉住）。
- **跨身份别名碰撞照常上报**：同 adapter 不同路径经字符归一化撞出相同派生别名时，第二身份不再被静默跳过，冲突进入日志待人工处置。
- **手动登记后徽标即时可见**：可执行项列表读取触发身份同步（此前需重启或手动调身份 API）。
- **旧库升级验证补全**：真实 v0.4.1 表结构建库升级测试（旧数据保留、迁移登记幂等）。
- **附带**：修复 0.4.1 更新任务在注册表锁内裸读任务终态的数据竞态（CI ubuntu 竞态检测器实证）。

## 升级说明

- 首次启动自动完成身份迁移，无需手工步骤；迁移效果可在设置页可执行项行的 `ag_*` 徽标与 `GET /v1/identity/agents` 核对。
- 旧版本二进制可直接升级本库；回退到 0.4.1 不受影响（新增表对旧版不可见）。
- 设计基线：[RFC-0018](docs/design/rfc/2026-10-28-rfc-0018-personal-agent-swarm.md)（Approved）与 [ADR-0017](docs/design/adr/ADR-0017-agent-identity-registry.md)；后续 0.5.1 起交付生命周期状态机与 Slot 体系。
