# ADR-0015：协作表格——自绘网格编辑器 + Go 服务端权威公式求值器

- 状态：Accepted（2026-09-28，随 RFC-0017 M1 裁定；OQ-1/OQ-3 定案）
- 关联：[RFC-0017](../rfc/2026-09-28-rfc-0017-spreadsheets.md)（协作表格）、RFC-0014（文档资产与事件流）、ADR-0014（per-doc 事件流）、ADR-0002（自绘 Web 前端）

## 背景与问题

RFC-0017 要求本地协作表格（编辑器 + 公式计算）并把编辑器/公式选型（OQ-1）与首版兼容集合、容量限额（OQ-3）留待 ADR 定案。约束：个人本地版离线运行（桌面 Wails 形态）、公式计算须经统一端口以服务端为权威（RFC §3.3"编辑器预演不成为权威"）、领域数据与事件不绑定组件私有格式（§6 风险表）。候选路径：

1. **成熟表格组件**（Univer / Handsontable / x-spreadsheet）：功能开箱即用，但各自冲突——Handsontable 商业许可；Univer（Apache-2.0）体积数 MB 且自带领域模型与客户端公式引擎，与事件流对齐成本高、公式权威冲突；x-spreadsheet 长期无维护。
2. **成熟公式库**（HyperFormula / Excelize Calc）：HyperFormula GPL/商业双许可且运行在 JS 侧（客户端权威）；Excelize 是 XLSX 文件库而非事件模型公式端口，作为 go.mod 首个重依赖仅为求值不划算。
3. **自绘 + 自研封闭子集**：与 ADR-0002 自绘前端纪律一致；公式子集封闭（RFC 明言"实际支持列表必须由用例集固定"），求值器规模可控、可全量单测。

## 决策

- **编辑器自绘**（`apps/web/src/pages/SheetEditorPage.tsx`）：窗口化网格（行 ×列双向视口）、公式栏、工作表页签、工具条（样式/行列结构），零新 npm 依赖；提交模型复用 DocEditorPage 工作台纪律（动作即 op、防抖聚合、409 重定基重放）。
- **公式求值在 Go 服务端**（`internal/sheet/formula.go`）：手写词法 + 递归下降 + AST 求值；编辑器不做本地预演——公式格派生值始终来自服务端 range 回读，本地编辑期间显示原式（斜体）直至回读定稿。同一工作簿版本同一公式规则版本（`FormulaRulesVersion = 1`）。
- **公式 v1 封闭集**：算术（`+ - * / ^` 与一元 ±、后缀 %）、比较（`= <> < > <= >=`，文本不区分大小写）、拼接（`&`）、引用（`A1 / $A$1 / Sheet!A1 / '中文名'!A1`、区域含跨表）、函数 `SUM AVERAGE MIN MAX COUNT COUNTA IF ROUND`（IF 惰性）。易变函数/宏/网络函数不支持。错误值封闭六枚：`#REF! #DIV/0! #VALUE! #NAME? #CIRC! #BUDGET!`。语义裁定：空引用按数值 0；算术接纳布尔（TRUE=1）；文本参与算术比较报 `#VALUE!`；区域内文本聚合忽略、显式文本参数拒收；循环引用 `#CIRC!`；求值预算耗尽 `#BUDGET!`。
- **结构改写 AST 级定稿进事件**：插删行列时解析全簿公式、平移受影响引用、被删区引用改写 `#REF!`，改写后的公式原文以 set_cells 随归一化事件落库——历史回放是纯机械应用，不依赖解析器行为（RFC §3.3 原文要求）。
- **容量限额（OQ-3 定稿，`internal/sheet/limits.go` 与 schema 同源）**：工作簿 ≤20 表；单表 ≤5000 行 ×200 列（列标上限 GR，对齐两家平台读取上限量级）；单批 ≤64 ops / 256 KiB / 1000 cells；单格文本 ≤8192 B；公式 ≤512 runes；全簿公式 ≤5000 格；单次全簿重算预算 20 万节点；范围读取 ≤10000 格/次。

## 后果与放弃方案

- 放弃成熟组件/公式库：代价是编辑器交互面首版克制（无填充柄/区域选择/图表）与求值器自维护；换来零依赖离线交付、公式服务端权威（多端一致与 agent 可信共享同一计算）、领域模型不绑组件格式。组件路径的重新评估触发条件：需要填充柄/合并单元格/图表编辑等重交互时。
- 性能基准（2026-09-28，12th Gen i7-12700，`go test -bench`）：万格 + 千公式全簿求值 **0.61 ms/op**；500 修订（每批 20 格写入，含逐批 Clone 试算）顺序回放 **38 ms/op**。两指标距 RFC §3.4 可接受上限有量级余量——物化快照缓存（§3.4"可重建的物化快照"）首版不做，按需折叠 + 进程内派生即可，超限再物化。
- 公式规则升级路径：新增函数/语义变更递增 `FormulaRulesVersion`——旧事件回放不受影响（归一化事件已定稿改写结果），仅派生面按版本分派重算。
