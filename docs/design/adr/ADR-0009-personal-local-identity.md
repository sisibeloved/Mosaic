# ADR-0009：个人版本地单用户免登录

| 状态 | Accepted |
|---|---|
| 日期 | 2026-08-25 |
| 关联 | [交付规划 D-2](../../plan/2026-08-25-delivery-plan.md)；RFC-0008；架构 §9.2 |

## 决策

- 个人版无登录界面：**OS 用户即 owner**，启动即用；`tenant` 固定为本地常量；
- Participant 模型保留：human = 本地 owner，agent = Agent Profile 实例化（RFC-0002）；
- RFC-0008 的 OIDC、多租户与角色矩阵归**服务端形态**：代码保留接口与判定结构，UI 不暴露；审计事件照常全量写入本地库。

## 后果与放弃方案

- 个人版不存在跨用户隔离面；导出/备份语义为"单用户全量"；
- 若未来引入多人类协作/服务端形态，按既有 RFC-0008 启用，不产生迁移死角（tenant 列与 actor 结构已在）；
- 放弃"本地 PIN/密码锁"作为 v1.0 范围（OS 级用户会话已提供基础隔离）；如需可作后续可选开关。
